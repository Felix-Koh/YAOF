# YAOF N150 私人定制固件

适用设备：Intel N150、4GB 内存、128GB 固态、四网口 x86_64 软路由。
基于 QiuSimons/YAOF 的 25.12 分支，基础 OpenWrt 版本固定为 25.12.5。

## 内置功能

- DAED：明确编入 `daed`、`luci-app-daed`，使用匹配内核的 `vmlinux-btf`。
- 网络唤醒：`luci-app-services-wolplus`。
- DDNS-Go：`ddns-go`、`luci-app-ddns-go`、简体中文页面。无需刷机后补装。
- UPnP：`luci-app-upnp`、`miniupnpd-nftables`。
- FullCone：`kmod-nft-fullcone`，保留 YAOF 的防火墙配置和 eBPF NAT 插件。
- IRQ 优化：`irqbalance` 默认启用，保留 `autocore-x86`，附带 IRQ 管理页面。
- KMS：`luci-app-vlmcsd`、`vlmcsd`。
- HomeProxy：`luci-app-homeproxy` 及其自动选择的依赖。

保留 YAOF 原有其他插件。本版没有预填订阅、域名、DNS 令牌或账号。

## 选哪个文件

优先下载名称含 `generic-squashfs-combined-efi.img.gz` 的文件：适用于 UEFI 启动，带可恢复的只读基础系统。

若 BIOS 使用传统 Legacy 启动，选择 `generic-squashfs-combined.img.gz`。
ext4 版为可写基础系统，另行提供；未明确需要时用 squashfs 版。

文件是完整磁盘镜像。写盘时会覆盖所选目标盘的数据；确认目标是软路由的固态盘或用于启动的 U 盘，并先备份原系统和配置。

## 首次启动

1. 校验下载文件与 `SHA256SUMS` 对应，再解压 `.img.gz` 得到 `.img`。
2. 用写盘工具将 `.img` 写入目标盘，选择与镜像对应的 UEFI 或 Legacy 启动方式。
3. 在固件能识别 `eth0`、`eth1`、`eth2`、`eth3` 四张物理网卡时，首次启动自动设置：`eth0` 为 WAN，`eth1`～`eth3` 桥接为 LAN。机壳的接口标号不一定与 Linux 编号相同，需要逐口插线确认。
4. 电脑接 LAN，访问 `http://192.168.1.1`，首次登录设置管理员密码。
5. WAN 默认沿用上游 DHCP 获取地址；需要宽带拨号时，在“网络 → 接口 → WAN”改为 PPPoE 并填写运营商账号。
6. 如果系统识别的网卡名称不是 `eth0`～`eth3`，自动布局不会执行，会沿用上游布局；请在接口页面按实际识别的网卡设置 WAN 与 LAN。

## 服务配置

- DAED、HomeProxy：内置后自行配置，启用其中一种透明代理。DAED 的独立管理界面默认端口为 `2023`。
- DDNS-Go：在服务页面启用后，打开端口 `9876` 的管理页，设置管理密码，再配置域名和 DNS 令牌。
- DDNS 获取 IP：WAN 直接拿到公网地址时可从接口获取；WAN 为上级路由分配的私网地址时，IPv4 应使用公网地址查询服务。不要将 WAN 私网地址写进公网 DNS。
- UPnP：按需启用，确认外网接口为逻辑接口 `wan`。
- FullCone：在防火墙页面检查开关。是否达到期望的 NAT 类型仍需实际网络测试。
- IRQ：默认启用 IRQ 均衡；可在相应管理页面查看，实际网卡吞吐须上机测量。
- KMS：按自己的合法批量许可环境配置。
- 网络唤醒：添加被唤醒设备的 MAC 地址，并确认被唤醒设备自身已启用 Wake-on-LAN。

## 空间与验证范围

内核分区为 128MB，根分区为 2048MB。128GB 固态剩余空间未预先格式化，可在系统中根据需要扩容或分区。

编译流程会检查解析后的配置、镜像软件清单以及安装后的根文件系统。必需组件缺失时禁止发布；通过后附带 `N150-validation.json`、完整编译配置与文件校验值。

发布成功代表编译和上述静态检查通过，不代表已经在这台实体 N150 上验证启动、网口顺序、代理连接、NAT 类型或吞吐。
